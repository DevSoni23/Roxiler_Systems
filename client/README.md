# Roxiler Systems — Frontend Client

React + Vite frontend for the Store Rating Platform.

## Features
- Built with React.js & Vite
- Custom Dark Theme Glassmorphism Design System (`index.css`)
- Context API for Global Auth State Management (`AuthContext.jsx`)
- Interactive Star Rating Selector
- Responsive UI for desktop and mobile devices

## Scripts
- `npm run dev` — Start local Vite development server
- `npm run build` — Build production bundle
